# flex-dir

Windows 파일 탐색기 대체 앱. **여러 폴더를 동시에 다루는 것**이 존재 이유다.

**한 칸에서 시작해 넷까지 나눈다.** 복사·이동이 페인 사이에서 일어나고, 폴더마다 뷰 모드와
정렬을 기억한다. shell 우클릭 메뉴와 클립보드는 탐색기와 그대로 호환된다 — 탐색기에서 복사해
flex-dir 에서 붙여넣는 것이 성립한다.

만든 사람이 매일 쓰려고 만든 개인 도구다. 그래서 판정 기준이 기능 개수가 아니다:

> 하루치 작업 루프에서 **기본 탐색기를 열 이유가 0인가.**

## 무엇이 되는가

| | |
|---|---|
| 레이아웃 | **1~4 분할** (프리셋 넷, 기본은 1분할). 활성 페인 표시. 스플리터로 비율 조정. 줄이면 **접히는 것**이라 다시 펴면 그대로다 |
| 탭 | 페인마다 탭 줄. 고정 · 이름 바꾸기 · 페인 사이로 끌어 옮기기 |
| 폴더 트리 | 창 왼쪽에 하나. 드라이브 · 네트워크 서버 · '네트워크 위치 추가' 로 등록한 곳. 고른 폴더는 활성 페인에서 열고, 페인 이동에는 따라가지 않는다. 타이틀바에서 트리 전체를 숨기고, 트리 툴바에서 펼친 노드를 모두 접는다 |
| 즐겨찾기 | 트리 맨 위의 `즐겨찾기` 그룹 아래에 모은다. 그룹을 접고 펴며 이름·순서를 바꾼다 |
| 설정 | 버전·업데이트 확인 · 시작 폴더(마지막/정해 둔 곳) · **숨김·시스템 파일 보기** |
| 탐색 | breadcrumb 주소줄 · 더블클릭 진입 · 상위로 · 페인별 뒤로/앞으로 |
| 툴바 | 폭이 모자라면 **덜 중요한 버튼 무리부터 접혀** `···` 메뉴로 간다. 이동·새로 고침·알려진 폴더는 안 접힌다 |
| 알려진 폴더 | 툴바 오른쪽 끝 드롭다운 — 홈 · 바탕화면 · 문서 · 다운로드 · 사진. **Windows 가 그 폴더에 붙여 둔 아이콘 그대로** |
| VS Code 로 열기 | 툴바 `[VS]` — **지금 폴더를 VS Code 로 연다.** 설치돼 있을 때만 켜진다 (App Paths 로 찾는다) |
| 터미널로 열기 | 툴바 `[>_]` — **지금 폴더에서 터미널을 연다.** Windows Terminal · PowerShell 7 · Windows PowerShell · 명령 프롬프트 · Git Bash 중에 고르거나, **실행 파일과 인자를 직접 적는다** (`{path}` 가 현재 폴더로 바뀐다). 설정에서 고르고 `[실행해 보기]` 로 확인한다 |
| 뷰 | 자세히 · 목록 · 타일 · 큰 아이콘. **폴더마다 기억한다** |
| 목록 | 자연 정렬(`file2 < file10`) · 폴더 먼저 · 유형/크기/날짜 그룹화 · **컬럼 폭 조절** |
| 썸네일 | shell 캐시를 그대로 쓴다. 비동기 · 스크롤이 지나가면 취소 |
| 선택 | `Ctrl+A` 전체 선택 · 목록 빈 공간을 드래그하는 선택 사각형 (`Shift` 추가 · `Ctrl` 반전) |
| 파일 조작 | 복사 · 이동 · 삭제(휴지통) · 이름변경 · 새 폴더 · 드래그앤드롭 |
| 컨텍스트 메뉴 | shell 우클릭 메뉴 그대로 — 설치된 확장이 전부 나온다 |
| 네트워크 | UNC(`\\server\share`) · 서버의 공유 목록 · 매핑 드라이브 |
| 갱신 | 외부 변경을 감지해 따라간다. **갱신 중에도 선택은 유지된다** |
| 프로세스 | single instance 상주. 창을 닫아도 살아 있어 다음 실행이 즉시 뜬다 |

대용량 폴더는 백그라운드로 열거하며 점진적으로 표시한다. 예산은 cold start 1.5s ·
상주 중 창 표시 100ms · 폴더 전환 후 첫 항목 150ms 이고, 계측은 앱 안에 있다
(`%APPDATA%\flex-dir\perf.log`).

## 설치

[**Releases**](https://github.com/solitasroh/flex-dir/releases/latest) 에서
`flex-dir-win-Setup.exe` 를 받아 실행한다.

- **관리자 권한을 묻지 않는다.** `%LOCALAPPDATA%\flex-dir\` 에 설치되고 시작 메뉴와
  바탕화면에 바로가기가 생긴다.
- **SmartScreen 경고가 뜬다.** 코드 서명 인증서가 없어서다. 넘기려면
  `추가 정보` → `실행` 을 누른다. 감수하고 싶지 않으면 아래 §직접 빌드하기 로 간다.
- .NET 런타임을 따로 깔지 않아도 된다 (self-contained).
- 새 버전이 나오면 앱이 알린다. **받는 것은 미리 끝내고 설치 시점만 고르게 한다** —
  `지금 설치` 를 누르면 곧바로 교체하고 재시작한다.
- 설정·사용 기록은 `%APPDATA%\flex-dir\` 에 남는다. 앱을 제거해도 지워지지 않으므로
  다시 설치하면 쓰던 상태로 이어진다.

설치하지 않고 보기만 하려면 같은 릴리스의 `flex-dir-win-Portable.zip` 을 풀어
`FlexDir.Host.exe` 를 실행한다 — 대신 자동 업데이트는 설치본에서만 동작한다.

Windows 11 x64 에서 만들고 쓴다.

### 직접 빌드하기

```
dotnet build -c Release
dotnet run --project src/FlexDir.Host
```

.NET 9 SDK 가 필요하다. 인스톨러를 굽는 것은 `scripts/pack.ps1` 이다
(`dotnet tool install -g vpk` 가 먼저 필요하다). 서명은 선택이다 —
`-SignThumbprint <지문>` 을 주면 서명하고, 주지 않으면 서명 없이 굽는다
(인증서 만들기는 `scripts/new-signing-cert.ps1`).

## 손에 익히는 키

**충돌하면 탐색기가 이긴다** — `Alt+←/→`(뒤로/앞으로) · `Alt+↑`(상위) · `F5` ·
`Ctrl+L`(주소줄) · `F2` · `Delete` · `Ctrl+C/X/V` 는 전부 탐색기와 같다.

분할이 있어서 생긴 것만 다르다.

| 키 | 동작 |
|---|---|
| `Tab` · `F6` | 페인 전환 |
| `Ctrl+Alt+C` / `Ctrl+Alt+M` | 선택을 **다른 페인 폴더로** 복사 / 이동 (직전에 있던 페인) |
| `Ctrl+Alt+O` | 다른 페인의 폴더를 이쪽에서 연다 |
| `Ctrl+Shift+1`~`4` | 자세히 · 목록 · 타일 · 큰 아이콘 |
| `Ctrl+1`~`4` | 이름 · 크기 · 유형 · 날짜순 (같은 키를 다시 누르면 방향 반전) |

전체 키 맵은 [`docs/DESIGN.md`](docs/DESIGN.md) §9 에 있다.

## 상태

혼자 쓰는 도구다. 한국어 UI 하나뿐이고, **자체 서명이라** SmartScreen 경고가 뜨고,
이슈·기능 요청을 받을 준비는 아직 안 돼 있다. 그래도 매일 쓰이고 있고 그것이 이 저장소의 유일한 품질 기준이다.
