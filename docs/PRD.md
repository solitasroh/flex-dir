# PRD — flex-dir v1

Windows 파일 탐색기 대체 앱. **여러 폴더를 동시에 다루는 것**이 존재 이유다.

## 1. v1 의 판정 기준

기능 개수가 아니다.

> **하루치 작업 루프에서 기본 탐색기를 열 이유가 0인가.**

탈출구가 하나라도 있으면 매일 안 쓰게 된다. 우클릭에 "Git Bash Here" 가 없으면
탐색기를 열고, 한번 열면 그날은 계속 거기서 한다. 그래서 v1 은 **좁게, 대신
구멍 없이** 만든다.

## 2. 포함 범위

| 영역 | 내용 |
|---|---|
| 레이아웃 | 좌/우 2분할. 활성 페인 표시. 스플리터 드래그로 비율 조정 |
| 탐색 | 주소 입력 · 더블클릭 진입 · 상위로 · 뒤로/앞으로 (페인별 히스토리) |
| 목록 | 이름 · 크기 · 유형 · 수정시각 컬럼. 대용량 폴더 데이터 가상화 |
| 뷰 모드 | Details · 목록 · 타일 · 큰 아이콘 (전환 가능) |
| 썸네일 | `IShellItemImageFactory` 로 shell 캐시 재사용. 비동기 · 스크롤 중 취소 |
| 정렬 | 자연 정렬(`file2 < file10`) · 폴더 먼저 · 다중 키 |
| 폴더별 기억 | 폴더마다 뷰 모드와 정렬을 기억 |
| 파일 조작 | 복사 · 이동 · 삭제(휴지통) · 이름변경 · 새 폴더. **페인 간 이동 포함** |
| 컨텍스트 메뉴 | shell 우클릭 메뉴 (`IContextMenu`) — 설치된 확장 그대로 노출 |
| 클립보드 | 탐색기와 상호 호환. 탐색기에서 복사 → flex-dir 에서 붙여넣기 성립 |
| 갱신 | 외부 변경을 감지해 자동 갱신. 갱신 중 선택 유지 |
| 프로세스 | single instance 상주. 두 번째 실행은 기존 창을 살린다 |
| 사용 로그 | 실행·사용 시간을 로컬에 기록 (도그푸딩 게이트 입력) |

## 4. 엣지케이스

| 상황 | 처리 |
|---|---|
| 폴더가 비어 있음 | 빈 상태 메시지. 목록 영역 자체는 유지 |
| 접근 권한 없음 | 오류를 상태 표시줄에 노출. 이전 경로로 되돌리지 않는다 |
| 경로가 사라짐 (탐색 중 삭제) | 상위 폴더로 자동 이동하고 사유를 알린다 |
| 열거 중 폴더 이탈 | 진행 중 열거를 취소한다. 이전 결과가 새 폴더에 섞이면 안 된다 |
| 썸네일 추출 실패 | 형식 아이콘으로 대체. 재시도하지 않는다 |
| 이름 충돌 (복사/이동) | shell 표준 충돌 대화상자를 그대로 쓴다 |
| 대용량 폴더 (10만+) | 백그라운드 열거 + 점진적 표시. 첫 항목까지 150ms 목표 |
| 외부에서 파일 변경 | 자동 갱신. 선택·스크롤 위치 유지 |
| 같은 폴더를 양쪽 페인에 | 허용. 각각 독립적인 뷰 상태를 갖는다 |

## 5. 성능 예산

수치는 **잠정**이다. 전작은 성급한 숫자로 잘못된 것을 최적화했다.
계측을 먼저 넣고 baseline 을 본 뒤 확정한다.

| 항목 | 잠정 목표 |
|---|---|
| cold start (최초 실행) | ≤ 1.5s |
| 상주 중 창 표시 | ≤ 100ms |
| 폴더 전환 후 첫 항목 표시 | ≤ 150ms |

## 6. 도그푸딩 게이트

**v1 완성 이후** 켠다. 만드는 중에 켜면 자기 발목을 잡는다.

- 기준: 지난 7일 중 **5일 이상** 사용
- 미달 시: 새 기능 작업 차단. **버그 수정만 허용**
- 근거: 전작 실패의 1원인이 "매일 안 씀" 이었고, 의지 표명은 게이트가 아니다
