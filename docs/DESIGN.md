# DESIGN — flex-dir

**실측 수치 스펙.** 원칙과 금지 목록은 [`UI_GUIDE.md`](./UI_GUIDE.md) 에 있다.

## 6. 상태 표현

| 상태 | 표현 | 근거 |
|---|---|---|
| **활성 페인** | 주소줄 테두리 accent + 하단 2px accent 라인. 비활성 페인은 크롬 배경을 `--win-bg` 로 낮추고 선택색을 `--sel-inactive` 로 강등 | 선택색 강등은 Windows 네이티브 관례(비활성 리스트뷰)라 학습 비용 0. 주소줄 강조는 시선이 이미 가는 곳이고 페인 전체 테두리보다 시각 소음이 적다 |
| 선택 항목 | accent 14% 배경, 모서리 3px | Win11 리스트 선택 관례. 불투명 배경이라 WPF 저비용 |
| 호버 | 검정 4.7% 배경 | Win11 subtle fill 값 그대로 |
| 키보드 포커스 | 1px `#1B1B1B` 실선 (inset). **활성 페인에서만** | 비활성 페인의 포커스는 무의미하므로 숨긴다 |
| 정렬 방향 | 헤더 텍스트 우측 8px ▲/▼ (Segoe Fluent `E70E`/`E70D`) | 탐색기와 동일 위치라 즉시 인지 |

## 7. 아이콘 (Segoe Fluent Icons)

| 버튼 | 글리프 |
|---|---|
| 뒤로 | `E72B` |
| 앞으로 | `E72A` |
| 상위 폴더 | `E74A` |
| 새로 고침 | `E72C` |
| 뷰 — 자세히 / 목록 / 타일 / 큰 아이콘 | `E8A4` / `E8FD` / `E8A9` / `E8A6` |

목업에서는 뷰 아이콘을 인라인 도형으로 대체했다. 구현에서는 위 글리프를 쓴다.

파일·폴더 아이콘은 **디자인 대상이 아니다.** Windows Shell 에서 온다 (SHELL_NOTES §아이콘).

## 8. 밀도 검증

| | 행 높이 | 600px 에 들어가는 행 |
|---|---|---|
| Windows 11 탐색기 (기본) | ~34 | 17 |
| **flex-dir** | **24** | **25** |

**+47%.** "탐색기 기반 + 정보 밀도 개선" 의 목표치를 만족한다.

## 10. 시안이 남긴 판단 — 결정 대기

시안 작성자가 임의로 정하지 않고 선택지와 근거를 함께 올린 항목들이다.

| # | 항목 | 시안의 제안 | 상태 |
|---|---|---|---|
| 1 | 활성 페인 표시 | 주소줄 accent + 선택색 강등 (전체 테두리·툴바 tint 는 기각) | **채택** — §6 반영 |
| 2 | Details 행 높이 | 24 채택. 22 는 밀도 +9% 지만 16px 아이콘 + 12px 텍스트의 상하 여백이 3px 로 떨어져 답답. 한글 가독성 손해 | **채택** — §2 반영 |
| 3 | 주소줄 위치 | 툴바 아래 별도 행 (같은 행에 두면 320px 페인에서 경로가 즉시 말줄임) | **채택** — §1 반영 |
| 4 | 밀도 옵션(24/28)을 설정으로 | 권장 | ⏸ **v1 범위 밖** — 설정 UI 자체가 MVP 제외다. v2 후보로 남긴다 |
| 5 | 비활성 페인 크롬 배경 강등 | 채택했으나 "과하면 이 항목만 제거해도 주소줄 강조 + 선택색 강등으로 충분" | ⏸ **미결** — 실물 보고 판단 |

4번과 5번은 확정되면 이 표와 본문을 갱신한다.
