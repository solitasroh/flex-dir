# Product

## Register

product

## Users

Windows 11에서 로컬 폴더, NAS, 매핑 드라이브와 WSL 경로를 오가며 개발하는 단일 사용자. 여러 폴더를 동시에 열고 복사, 이동, 비교하는 흐름이 하루 작업의 중심이다.

## Product Purpose

Windows 파일 탐색기를 열지 않고도 하루치 파일 작업을 끝내는 다중 페인 파일 관리자다. 성공 기준은 기능 수가 아니라 1~4개 페인 사이를 빠르게 왕복하면서 탐색기 호환 파일 조작을 안정적으로 수행하는 것이다.

## Brand Personality

익숙함, 밀도, 절제. Windows 기본 도구처럼 설명 없이 이해되고, 많은 항목을 다뤄도 조용하며, 사용자의 작업보다 앞에 나서지 않는다.

## Anti-references

- 기능을 한 화면에 과도하게 쌓아 조작 위치를 찾기 어렵게 만드는 파일 관리자
- Windows 관례와 다른 키보드·마우스 동작
- 장식적인 카드, 과한 색, 불필요한 애니메이션처럼 파일 작업의 밀도를 낮추는 UI
- UI와 상태, shell 호출을 한 객체에 섞어 수정과 검증을 어렵게 만드는 구조

## Design Principles

- 탐색기에서 익힌 동작을 그대로 가져온다.
- 여러 폴더 사이의 왕복을 가장 짧게 만든다.
- 자동 이동보다 사용자가 직접 둔 위치와 상태를 존중한다.
- 저장소와 shell 호출은 UI 응답성을 막지 않는다.
- 화면에 없는 기능과 상태도 테스트 가능한 명령과 모델로 유지한다.

## Accessibility & Inclusion

공식 WCAG 목표는 정해지지 않았다. 키보드만으로 핵심 탐색과 파일 조작이 가능해야 하며, 아이콘 버튼에는 `AutomationProperties.Name`과 툴팁을 제공한다. Windows DPI 배율과 라이트·다크 테마에서 텍스트와 상태 구분이 유지돼야 한다.
